# Oliver Thomas Portfolio Site

A minimal, one-page static portfolio designed as a recruiter-friendly reel selector.

## What to edit

Open `index.html` in any text editor and replace:

- The three `https://www.youtube.com/` links with your direct reel URLs
- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL`
- `YOUR_YOUTUBE_URL`
- `YOUR_PIXOLLIE_URL`
- `YOUR_CV_URL`

You can also tweak the About copy or credits directly in the HTML.

## Preview locally

Double-click `index.html` and it will open in your browser.

## Free hosting options

### GitHub Pages
1. Create a GitHub account/repository.
2. Upload `index.html`.
3. In repository Settings → Pages, choose the main branch.
4. GitHub will give you a free public URL.

### Netlify
Drag the whole folder into Netlify's deploy interface.

### Cloudflare Pages
Connect a Git repository and deploy the folder as a static site.

## Custom domain later

You can add a paid domain later without rebuilding the site.
